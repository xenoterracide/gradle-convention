# Agent Workflow

When doing ANY work that modifies files in this repository, follow the [pull-request skill](.agents/skills/pull-request/SKILL.md) workflow.

This includes:
- Fixing bugs
- Adding features
- Refactoring code
- Debugging issues
- Cleaning up or formatting
- Any task that results in changed files

The workflow ensures changes are properly committed, pushed, and submitted as pull requests with appropriate conventional commit messages.
